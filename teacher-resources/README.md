Five classroom resources for the free K–6 StoryDogs activity. Prepared October 4, 2026.

Website handoff: `teacher-resources/website-implementation-note.md`.

Print on US Letter paper. The cards are single-sided, eight per page; print at 100% and cut on the dotted lines. The one-page cheat sheet has light colors and the existing dog illustrations, with labels that remain usable in grayscale.

The first six sentence starters follow Pixar Story Rule #4. The seventh line, “Ever since then,” is a StoryDogs extension. The original example, The Cake That Went for a Walk, shows connected trouble, a character-driven climax, and a visible change afterward.

## Review and integration

The documents are ready for review. They use WHO?, LIFE / WANT, UH-OH!, TROUBLE, WORSE!, CLIMAX, and CHANGE as requested. The implementation note identifies differing labels in the inspected website code and describes how to preserve both student answers per stage in the narrative report.

Adding files does not change the report formatter or resource navigation. Follow the separate implementation note to connect the downloads and update the report. Deployment is a separate step.
